# Plain-English guide to common SEC filings

| Form | What it is | When |
|---|---|---|
| 10-K | Annual report: full audited financials, business description, risk factors | Within 60-90 days after fiscal year end |
| 10-Q | Quarterly report: unaudited financials and management discussion | Within 40-45 days after each of the first three quarters |
| 8-K | "Current report" on a material event, listed by item number (below) | Usually within 4 business days of the event |
| 4 | An insider (officer, director, 10% owner) bought, sold or was granted shares | Within 2 business days |
| 3 / 5 | First insider ownership statement / annual catch-up of insider changes | |
| DEF 14A | Proxy statement: board, executive pay, shareholder votes | Before the annual meeting |
| SC 13D / 13G (Schedule 13D/13G) | Someone owns more than 5%; 13D = may seek influence, 13G = passive | |
| S-1 / 424B | Registration and prospectus for selling new shares (IPOs, offerings) | |
| 20-F / 6-K | Foreign company's annual report / current report | |
| /A suffix | An amendment to an earlier filing | |

## 8-K item numbers
| Item | Meaning |
|---|---|
| 1.01 / 1.02 | Entered / ended a material agreement |
| 1.05 | Material cybersecurity incident |
| 2.01 | Completed acquisition or sale of assets |
| 2.02 | Results of operations: the earnings release (usually Exhibit 99.1) |
| 2.05 / 2.06 | Restructuring costs / material impairment |
| 3.01 | Delisting notice or listing-rule failure |
| 4.01 / 4.02 | Auditor change / past financials can no longer be relied on |
| 5.02 | Director or officer arrives, leaves, or pay changes |
| 5.07 | Shareholder vote results |
| 7.01 | Regulation FD disclosure: presentations, sometimes guidance updates |
| 8.01 | Other events the company chooses to report |
| 9.01 | Financial statements and exhibits attached |

Source: SEC Form 8-K instructions, https://www.sec.gov/files/form8-k.pdf ; SEC "Investor Bulletin: How to read an 8-K", https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins/how-read-8
